#### Latest work

**Tiered Language Models.** Open-weight LLMs that expose extra capabilities only to holders of a secret key. The key is a permutation of the model's weights, so the public release behaves like a standard model while keyed users unlock the private tier from the same checkpoint. I pretrained and fine-tuned models at 180M and 650M scale from scratch.

*Toward Open Weight Models Without Risks: Separating Public and Private Capabilities in LLMs*. First author, under review at ICLR 2027. [Paper](https://arxiv.org/abs/2606.21638) · [Code](https://github.com/McGill-NLP/tiered-language-models)
